### User or client:
Anyone who handles large amounts of files/images
### Problem:
Storage space limitations
### Proposed solution:
Graphical interface that allows browsing of local files with option to encode, decode, and view files.
### Success criteria:
  1. Encoding files to a smaller size
  2. Lossless decoding of files
  3. Easy browsing of local files
  4. Opening encoded file opens app and displays the file
  5. Multiple supported file types
### Investigation:
  - How can different types of files be displayed inside of one app?
  - How to open any file using the coded program?
